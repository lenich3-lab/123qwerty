# Чуть добрее

Пикалка с теплом: мягкие созвучия и короткие подсказки для добрых действий. Три направления — для себя, для других, для мира. В каждом восемь карточек: они перемешиваются без повторов до конца подборки. Нажатия считаются только в текущей сессии; это число пауз, а не выполненных добрых дел.

## Открыть

После публикации через GitHub Pages сайт доступен по адресу https://lenich3-lab.github.io/123qwerty/.

Настройка публикации: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Отправка кода сама по себе не включает Pages.

Локально откройте `index.html` в браузере или выполните из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Зависимости, внешние шрифты, аккаунт и сборка не нужны. Звуки синтезируются в браузере через Web Audio API после нажатия. Пробел вне элементов управления запускает новую карточку. Есть три звучания, регулировка громкости и отключение звука. При недоступном аудио карточки продолжают работать. «Поделиться теплом» копирует текст; доступ к буферу зависит от разрешений браузера и безопасного контекста (HTTPS или localhost).

Персональные данные не отправляются и не сохраняются. Предыдущая версия пикалки сохранена в ветке `pikalka`.
