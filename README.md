# Уроко — мастерская репетитора

Первая рабочая версия приложения для подготовки уроков по школьным предметам и к ОГЭ/ЕГЭ. Один материал доступен в трёх связанных видах: план с конспектом, майнд-карта и презентация.

## Что уже работает

- Библиотека уроков с поиском, созданием, копированием и удалением.
- Пустой шаблон и редактируемые примеры по математике, русскому языку и биологии.
- Предмет, класс, формат подготовки, цель урока, домашнее задание и личные заметки.
- Этапы с таймингом, типом и многострочным конспектом; добавление, перестановка, дублирование, удаление с подтверждением.
- Диаграмма распределения времени с резервом или превышением плана.
- Майнд-карта: тема → этапы → конспект, масштабирование и переход к редактированию ветки.
- Презентация из конспекта: три оформления, показ со стрелками, автоматическое деление длинного текста. Личные заметки репетитора в неё не включаются.
- Экспорт плана для печати / сохранения в PDF, карты в SVG, автономной презентации в HTML и редактируемых уроков в JSON.
- Импорт JSON добавляет независимые копии, не перезаписывая текущие уроки. Максимум 100 уроков, 40 этапов в уроке и 2 МБ для импортируемого файла.
- Автосохранение на этом устройстве, предупреждение о недоступном хранилище, резервная копия библиотеки.

## Открыть приложение

GitHub Pages: https://lenich3-lab.github.io/123qwerty/

Для публикации: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Следующие отправки в `main` обновляют сайт после завершения развёртывания Pages.

Для локальной работы из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Можно использовать `npm start` или открыть `index.html` напрямую, но стабильнее работать через сервер: поведение хранилища для `file://` различается между браузерами. Установка зависимостей и сборка для запуска не нужны. Все шрифты системные; приложение не обращается к сторонним API.

## Как подготовить урок

1. Нажмите «Новый урок», выберите чистый лист или пример.
2. Укажите название, предмет, класс, формат и длительность. Сформулируйте цель.
3. Заполните этапы. Каждую мысль или задание в конспекте пишите с новой строки.
4. Посмотрите на майнд-карту и проверьте структуру.
5. Переключитесь на презентацию, выберите оформление, запустите показ.
6. Через «Экспорт» скачайте нужные материалы и JSON-копию для сохранности или переноса.

Примеры — редактируемые заготовки, а не актуализированный банк экзаменационных заданий. Требования, критерии и задания сверяйте с материалами ФИПИ для нужного года.

## Хранение и границы первой версии

Уроки хранятся в `localStorage` этого браузера и этого адреса сайта (`uroko.workspace.v1`). Они не синхронизируются между устройствами или браузерами; очистка данных сайта удаляет их. Скачивайте резервную копию JSON. При ошибке сохранения материалы остаются в открытой вкладке и доступны для экспорта. Не редактируйте одну библиотеку одновременно в нескольких вкладках: сохраняется последняя записанная версия.

При повреждённых данных приложение показывает примеры и предупреждение, не изменяя исходную запись до следующего сохранения. Перед новой записью исходные данные сохраняются под ключом `uroko.workspace.v1.recovery`.

В этой версии нет регистрации, облачной базы, совместной работы, встроенного банка заданий, генерации ИИ и экспорта в PPTX. Презентация скачивается в HTML и работает без приложения, в том числе без интернета. PDF формируется через стандартную печать браузера. Это проверяемая основа для следующего этапа: аккаунтов, базы данных и генерации материалов.

## Проверки

Node.js 18+ и Python 3 нужны только для вспомогательных команд; Playwright — только для браузерных тестов.

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

Если Chromium уже установлен, тесты используют `/usr/bin/chromium`; другой путь можно задать через `CHROMIUM_PATH`. Тестовый сервер запускается автоматически на свободном локальном порту и останавливается после проверки.

Тесты проверяют создание и сохранение уроков, операции с этапами, связь плана с картой и слайдами, автономный экспорт HTML, валидность SVG, печатный PDF, импорт и его ошибки, недоступное и повреждённое хранилище, безопасный вывод HTML-текста, длинные конспекты, мобильную вёрстку и клавиатуру.
