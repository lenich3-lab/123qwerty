# Пикалка

Маленький синтезатор звуков на Web Audio API: кнопка «ПИК», настройка высоты и громкости, эффекты «Монетка», «Робот» и «НЛО». Пробел запускает обычный пик, когда фокус находится вне элементов управления. Одновременно звучит один эффект.

## Запуск

Откройте `index.html` в современном браузере или запустите локальный сервер:

```sh
cd /workspace/123qwerty
python3 -m http.server 8000 --bind 0.0.0.0
```

Нажмите «ПИК»: браузер разрешает звук после действия пользователя. Зависимости и сборка не нужны. Шрифт при отсутствии сети заменяется системным.
